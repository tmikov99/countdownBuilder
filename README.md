# ⏳ Countdown Builder

A simple, customizable countdown timer for your browser.

## Features

- Live countdown (days, hours, minutes, seconds) for upcoming events
- Custom title and background (image or video)
- Set target date and time
- Settings saved in `localStorage`

## Usage

1. Open `index.html` in your browser.
2. Click **⚙️ Edit** to:
   - Set a title
   - Add an image or video URL
   - Choose a target date and time
3. Click **Save Changes** to apply.

All settings are saved automatically and reloaded on refresh.

## Background Media

- **Image:** Use `.jpg`, `.png`, etc.
- **Video:** Use `.mp4`, `.webm`, or `.ogg` (autoplays, loops, muted)
